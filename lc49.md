# step1
思考ログ
- つまり同じ文字数かつ同じ文字を使っていればよい
- 初めに思いつくのは各文字をalphabet順に並べ替えて前から見ていくことだがこれだとO(n^2)
- リストの要素は全て同じ文字数と仮定して良いのか?
- alphabet順に並び替えればanagramは同じ文字になるはず

'''python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagram_maps = defaultdict(list)

        for word in strs:
            sorted_word = "".join(sorted(word))
            anagram_maps[sorted_word].append(word)

        return list(anagram_maps.values())
'''

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        sorted_str_to_original = defaultdict(list)

        for letter in strs:
            letter_to_integer = defaultdict(int)
            for s in letter:
                letter_to_integer[s] += 1
            sorted_str_to_original[frozenset(letter_to_integer.items())].append(letter)

        return list(sorted_str_to_original.values())
```
- 数値を使って得場合は、大文字小文字の制限を考えないと演算がおかしくなるということには気づかなかった.
- step1でanagram_map(最初に定義する変数名)としたものについて,良い感じの変数名があればと思ったが、"sorted_str_to_original"でよさそう
- "".join or tuple問題。[これ](https://github.com/katataku/leetcode/pull/11#issuecomment-2527978460)を見た上で個人的には"".joinで良いかなと思った
